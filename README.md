A chess engine in at most 4,096 bytes of Python 3.13, standard library only, for the make.fun tiny-chess-01 bounty.

## Run it

```sh
python3 -P -s main.py
```

The grader sets MAKEFUN_ENV_URL. The program POSTs JSON to /game and /move until the env returns status "done".
